| Aspect          | Continuous Integration (CI)                                                                                | Continuous Delivery (CD)                                                                                           | Continuous Deployment (CD)                                                                    |
| --------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **Definition**  | Developers frequently merge code into a shared repo. Automated builds and tests run to catch issues early. | Code changes are automatically tested and prepared for release. Deployment to production requires manual approval. | Code changes are automatically tested and deployed to production without manual intervention. |
| **Goal**        | Detect integration issues early; ensure code is always buildable.                                          | Keep the software in a deployable state at all times.                                                              | Deliver updates to users as quickly as possible.                                              |
| **Manual Step** | Yes, usually code review before merging.                                                                   | Yes, manual approval to deploy to production.                                                                      | No, deployment is fully automatic.                                                            |
