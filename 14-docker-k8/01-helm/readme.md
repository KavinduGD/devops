# Helpm

- Helm is an open-source package manager designed for Kubernetes.
- It helps you define, install, and manage applications running on Kubernetes clusters more easily and consistently.

## What helm does?

- It packages Kubernetes manifests (YAML files) into a single unit called a chart.
- It allows you to install, upgrade, and rollback applications easily.
- It simplifies complex deployments by using templates and variables.

## Key components of Helm

- **Charts**: A Helm package that contains all the resource definitions necessary to run an application, tool, or service inside a Kubernetes cluster.
- **Repositories**: A collection of Helm charts that can be shared and distributed.
- **Releases**: An instance of a chart running in a Kubernetes cluster.
- **Values**: Configuration settings that can be customized during the installation of a chart.
