# DevOps Learning Journey

Welcome to this comprehensive DevOps learning repository. This project documents a structured path through the essential tools, practices, and technologies that define modern DevOps engineering.

## What I Have Learned
Throughout this journey, I have gained hands-on experience with:

*   **Core DevOps Principles**: Mastering the software development lifecycle from code commit to production deployment.
*   **Infrastructure as Code**: Provisioning and managing complex cloud infrastructure on **AWS** using **Terraform** and CloudFormation principles.
*   **Configuration Management**: Automating server setup and application deployment with **Ansible**, using playbooks, roles, and collections.
*   **CI/CD Pipelines**: Building automated build, test, and deployment workflows using **Jenkins**, **GitLab CI**, and **GitHub Actions**.
*   **Containerization & Orchestration**: Packaging applications with **Docker** and orchestrating them at scale with **Kubernetes** (including EKS and Kops).
*   **Monitoring & Logging**: Setting up observability with AWS **CloudWatch** and integrating monitoring into the deployment pipeline.
*   **GitOps**: Implementing declarative continuous delivery using **ArgoCD**.
*   **Scripting**: Automating routine tasks with **Bash** scripting and **Python**.
